## Overview

**Latent** is a macOS workspace for browsing, searching, and curating a personal photo archive.
It indexes previews and metadata while originals stay on local disks, external drives, or mounted cloud drives.

Search by meaning or by a reference image, revisit related photographs across years, and arrange selections into Sequences.
Ratings, captions, and review tools help turn an archive into new work.

Latent is a developer preview that runs from source on Apple Silicon Macs.
The public repository contains setup instructions and the current project status.
