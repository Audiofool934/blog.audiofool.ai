## Overview

**Moondog** is a listening room in your terminal.
It turns listening history into a taste profile you can open, question, and correct.

The profile works without a model or a music-service login.
An optional agent can talk music with you, find songs, and shape a playlist.

The project homepage introduces the room, while the public repository contains installation instructions and the current source.
